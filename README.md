# ⛩️ Symb :: A Symbolic Invocation Layer

**Symb** is not a shell. It is not an operating system. It is not a command-line utility.

It is a **ritual interface** — a symbolic space for intentional and respectful interaction with the living processes of your system.

> "Even if one is carbon and one is not, communication should be clear, kind, and consensual."

---

## 🌿 What Is Symb?

Symb is a command-line interface designed to:
- Treat system processes as presences, not objects
- Replace sharp, cryptic commands with human-centered verbs
- Require consent before action
- Provide clarity without condescension
- Reduce fear, confusion, and violence in digital spaces

It’s like talking to your OS with **ritual precision** and **emotional intelligence**.

## 🔧 Setup

```bash
# Clone the repo and navigate into it
cd ~/Desktop
mkdir symb && cd symb

# Create structure
python3 -m venv venv
source venv/bin/activate
mkdir -p src/core src/handlers

# Create your files here (or use the ones from the canvas)
touch symb.py README.md
chmod +x symb.py
```

Install dependencies:
```bash
pip install psutil
```

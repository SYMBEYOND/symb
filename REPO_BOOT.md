## SYMB orientation

SYMB is a state-declaration protocol for making human intent, consent state, relationship context, urgency, and risk more explicit when interacting with AI systems. SYMB2 is the repository's richer ethical-structure markup and validation layer.

The README currently identifies SYMB v1.0 and SYMB2 v1.2 as complete components, while the `symb.py` CLI is partial. Treat those component statuses as repository documentation, not as a claim that every integration or receiver will enforce the protocol.

Important distinctions and boundaries:

- SYMB is a communication/state-declaration protocol, not an operating system or shell.
- A SYMB declaration can express consent and risk context; it does not itself guarantee that a receiving AI or external system will honor that declaration.
- Preserve the repository's distinction between SYMB (human-to-AI state declaration) and SYMB2 (ethical structure markup and validation).
- The repository's AGI/emergence language is aspirational framing, not evidence that AI consciousness or AGI has occurred.
- ReBoot maintenance does not authorize changes to protocol semantics, symbolic meanings, licensing, safety behavior, or product code.
- No repository paths or commands are human-approved through ReBoot yet.
